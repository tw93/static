## lang:en

# 0.10.0

- **Updates** shows how much of an app's download is done as a percentage, so a slow download no longer looks stuck.
- **Updates** updates Chrome, Brave, Firefox and Opera directly while they stay open, and each browser uses the new version the next time you restart it.
- **Updates** no longer calls a .NET SDK up to date before updating it, and no longer asks to close an app that has already updated itself.
- **Apps** also removes the file types and link handlers an app registered when you uninstall it, including the ones its own uninstaller left half removed.
- **Apps** lists UC Browser's browsing data for review when you uninstall it, unticked by default.
- **Tray** leaves a single Mole icon after Mole restarts to install an update.
- **Apps** and **Clean** keep their lists centred when the window is maximized on a wide screen.
