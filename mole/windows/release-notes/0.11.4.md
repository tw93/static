## lang:en

# 0.11.4

- **Tray** opens the status panel right where docks such as MyDockFinder place it, instead of showing it elsewhere first.
- **Analyze** keeps folders Mole is not allowed to read in the list, marked No access, instead of leaving them out.
- **Apps** keeps the refresh spinner visible long enough to show the list was checked again.
- **Interface** lines up loading dots and icons with the capital letters of the text beside them.
- **Languages** use one name for Keep Screen On in Japanese and Italian, and correct the Korean wording for memory pressure.
