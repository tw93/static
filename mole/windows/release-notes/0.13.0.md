# 0.13.0

- **Apps** updates PowerShell 7.6 again, where the update used to stop at once with error 0x8A150014.
- **Clean** ticks thousands of Recycle Bin items at once without freezing the window.
- **Apps** no longer asks you to quit a background service such as Microsoft PC Manager's before uninstalling, and leaves stopping it to the app's own uninstaller.
- **Apps** no longer counts Acrobat's process as Premiere Pro, Bridge, Lightroom or Media Encoder when only their uninstall entries remain, and names the app that ignored a quit request instead of showing the same prompt again.
- **Optimize** runs the system file repair it offers during the free trial too, including after the last free optimization, and checks disk health again before it starts.
- **Interface** keeps titles and labels whole when Windows Text size is turned up, while Display scale still enlarges the whole window.
- **Languages** draws Japanese, Korean and Chinese in each language's own fonts, so Japanese no longer shows Chinese character forms on a Chinese Windows.
- **Apps** no longer files Claude and other apps an installer provisioned for every account under Preinstalled.
- **Status** explains, when you hover over the battery card, that a battery plugged in but not charging may be paused by the PC maker's battery protection or Windows smart charging.
- **Tray** opens its panel the moment you click the icon, and a double-click no longer opens the main window, which is the panel's Open Mole button.
