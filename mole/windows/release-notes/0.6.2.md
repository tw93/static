## lang:en

# 0.6.2

- **Updates** checks running apps again before installation and each retry, keeping apps opened while waiting from being updated without confirmation.
- **Updates** checks the installed version after a provider refusal and retains installer error codes, so an app already at the target version no longer remains marked as failed.
- **Clean** simplifies quitting a single app and groups Force Quit with Cancel, while preventing double-clicks and held keys from confirming a forced quit.
- **Uninstall** keeps your latest choice to preserve data when scans finish later and rechecks shared data before each elevated removal.
- **Analyze** keeps the current folder when refreshing its drive and respects your latest drive choice, including retries after a failed scan.
- **Status** refreshes the process list when reopening the tray and preserves a disabled main window during normal quit while its dialog is active.
- **Diagnostics** keeps bounded local update records with confirmation outcomes, installed versions and return codes to help investigate failed updates.
