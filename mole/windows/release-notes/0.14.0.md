## lang:en

# 0.14.0

- **Apps** keeps an app you just updated as updated after the list refreshes, no longer offers an update whose version is already installed, and tries a download once more when the connection drops.
- **Analyze** shows a file in File Explorer when you double-click it instead of opening it, so an installer or script no longer runs by accident.
- **Apps** never moves a Steam game library to the Recycle Bin with an uninstall, even when part of it cannot be read, and leaves an Electron app's profile unticked when Remove data and settings with apps is on.
- **Apps** shows what removing a built-in Store app such as Xbox really frees, since Windows keeps the app for other users and only its data goes.
- **Check for Updates** answers in one sentence when Mole is up to date, with a link to Version History.
- **Settings** draws its dropdown menus on a solid background, so the switches behind them no longer show through.
- **Tray** rests while the screen is off or the PC is locked instead of sampling the CPU every second.
- **Status** shows CPU usage on PCs whose Windows performance counters are broken, and Doctor says how to repair them.
- **Compatibility** explains on Windows older than Windows 10 version 2004 that Mole needs Windows 10 22H2 or Windows 11 instead of closing at once, and Doctor no longer asks Windows 10 LTSC 2021 to update.
- **Interface** centres button and tab labels in Chinese again, which sat slightly low since 0.13.0.
