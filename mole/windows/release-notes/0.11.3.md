# 0.11.3

- **Tray** opens the status panel under the icon you clicked, so docks that show tray icons in their own bar, such as MyDockFinder, no longer make it jump.
- **Clean** shows how many items this run cleaned and what that space costs as SSD storage, and the result details explain how the price is worked out.
- **Results** in Clean, Uninstall and Optimize show skipped items in gray and failures in orange, so what was left alone reads apart from what went wrong.
- **Tray** keeps the lifetime totals inside the panel's card, brightens them on hover and shows what the space you cleaned costs as SSD storage.
- **Planets** spin about their own tilted axis, so Jupiter's bands stay level and Earth's poles stay put.
- **Tray** shows the runner facing left by default, as on the Mac, and keeps the direction you already chose.
- **Support** keeps a local record of what each Clean, uninstall, Optimize run and Recycle Bin move did, with counts and reasons but no file names or paths, for the diagnostic report.
