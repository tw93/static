## lang:en

# 0.11.5

- **Optimize** only checks system files during a run and offers Repair system files in the results, since a repair can download from Windows Update for up to half an hour.
- **Optimize** stops showing Requesting admin access once you approve the prompt, and says the admin tasks are running instead.
- **Clean** shows Requesting admin access and then Cleaning items that need admin access, instead of Preparing clean while the prompt is up.
- **Check for Updates** opens at once with the answer from Mole's last automatic check and refreshes it in place.

# 0.11.5

## lang:ko

# 0.11.5

- **최적화** 실행 중에는 시스템 파일 검사만 하고, 복구가 필요하면 결과 화면에서 시스템 파일 복구를 따로 제공합니다. 복구는 Windows Update에서 내려받으므로 최대 30분 정도 걸릴 수 있습니다.
- **최적화** 관리자 권한을 승인한 뒤에는 관리자 접근 권한 요청 중에 머물지 않고 관리자 권한이 필요한 항목 실행 중으로 표시합니다.
- **정리** 승인을 기다리는 동안 관리자 접근 권한 요청 중, 승인 후에는 관리자 권한이 필요한 항목 정리 중으로 표시하며 더 이상 정리 준비 중에 멈춰 보이지 않습니다.
- **업데이트 확인** 바로 열려 최근 자동 확인 결과를 보여 주고, 그 자리에서 결과를 새로 고칩니다.
