## lang:en

# 0.25.0-beta.4

- **Updates**: When some apps have updates and others are already up to date, the header now names both lists with their counts and Mole shows one at a time, starting with the available updates.
- **Uninstall**: An app that Mole can tell came from Scoop, winget or the Microsoft Store now names that source at the end of its row.
- **Installer**: The installer is about a fifth smaller.
- **AI Tool Cleanup & Care**: A removed Pi's folder is no longer offered while it still holds the instructions, skills, prompts, themes, extensions or packages you kept for Pi, and a removed omp's folder is listed, unticked, once nothing of yours is left in it.
